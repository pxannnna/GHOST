# Local pressure panel

Start the existing Hub with `python -m uvicorn services.hub.app:app --host 127.0.0.1 --port 8000`. The server automatically looks for the pressure board at startup, including when it is plugged in later. Open **02 Floor detection** to view it. Once about three seconds of stable readings arrive, it automatically calibrates with a fixed starting floor of **3** and runs continuously. Startup and every reconnect must take place on floor 3. Subsequent floor estimates still follow real pressure changes. There is no manual calibration control. A specific currently attached serial port can also be selected after disconnecting. G, 1, 2 and 3 are supported; LG has no survey.

The adapter reuses Anna's `BoardClient` and `FloorEstimator` without changing them. The default survey is copied from Anna's `room-location` commit `3ccca5a` (8 November USB-board measurements); this is a configuration update, not a merge of other branch changes. Plot geometry and acoustic ranking are unchanged.

Automatic discovery recognizes ArduPilot/StellarH7 device names or USB VID:PID `1209:5741`, observed on this StellarH7V2. It does not select the ESP32 USB interface `303A:1001`. Ambiguous automatic matches require manual selection. After selection, VID, PID and USB serial number identify the same board across COM-number changes. Devices without a serial number fall back to the selected port. USB identification is followed by a MAVLink heartbeat and valid pressure-data check.

The server owns the serial connection; browsers do not need Web Serial permission. `/pressure/devices` and `/pressure/state` are read endpoints. POST `/pressure/connect` accepts `{"port":null}` for automatic selection, or a currently listed port. `/pressure/disconnect` releases the board. Calibration is intentionally not persisted: startup and reconnect reset the baseline and automatically zero on floor 3 once readings settle. Other programs must release the port before connecting.

Pressure and floor events go to the Hub. The page reads its dedicated controller state so mock events cannot overwrite live pressure. Disconnected or stale readings cannot show a valid floor, calibrate, or update the acoustic floor filter. **Use detected floor for room search** explicitly applies a fresh, settled result to 03; it does not automatically re-rank during an audio measurement. The user can still change the acoustic filter independently.

Tests cover generic Windows names, multiple boards, COM renumbering, exclusion of unrelated receivers, reconnect baseline invalidation, event validation and stale-state handling. Hardware verification: automatic connection on COM6 with a second ESP32 board on COM5, live pressure and calibration at the user-confirmed third floor. COM6→COM12 reconnect is tested with a simulated device; no physical renumbering was required.
